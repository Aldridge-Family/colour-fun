# Colour Fun — colour-by-number for Lilly & Maddy

Home-screen web app for the Lenovo tablet. Works offline once opened.

Live at: https://aldridge-family.github.io/colour-fun/

On the tablet: open the link in Chrome, tap ⋮ → **Add to Home screen** / **Install app**.

Every push to `main` redeploys automatically via `.github/workflows/pages.yml`.
